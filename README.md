# Games for fx-CG50 graphic calculator

Here you can find game files and installation instructions for your calculators. There are many more available online, and I only provided here those that I tested. 
It is important to notice that the calculators have very limited space, so if you want to install big games, you will have to delete others.

# Transferring games
The necessary game files (usually just one unless specified differently below) are simply copied into the calculator's memory directly from the laptop using the following steps:
1. Connect the calculator to the computer using the mini USB to USB-A cable (**not** the circular one)
2. Select the first option in the calculator menu when offered (F1) for file transfer
3. Locate the calculator on file explorer on your laptop and copy paste the files you wish to use directly into the root directory (do not put it in folders unless specified)
4. Right click the calculator drive and select option eject. Ignore any error messages and follow the instructions on your calculator which will include pressing EXE and EXIT to install the games
5. You can now disconnect the calculator from the computer. The games are located at the bottom of the home page of the calculator

# Native support
To play the following games you only need to copy the files on the device. File names are given in brackets:
- Blackjack ([Blackjack.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/Blackjack.g3a))
- Doom ([CGDoom.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/CGDoom.g3a) AND [doom.wad](https://github.com/msbrickle/fx-CG50-games/blob/main/doom.wad). Both files are required to load the game (arrows for walking, ALPHA is shooting)
- Minecraft ([minecraft-FX.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/minecraft-FX.g3a) AND [fxcraft](https://github.com/msbrickle/fx-CG50-games/tree/main/fxcraft). Both files are required to play the game (ALPHA is for switching modes, 8 is for walking forwards, arrows for direction, 7 is for breaking blocks, 9 is for placing. In floating mode, you can fill your item library from VARS)
- Minesweeper ([minesweeperprizm19.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/minesweeperprizm19.g3a))
- Snake ([Snake.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/Snake.g3a))
- A multiplayer racing sim
   - [racing.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/racing.g3a)
   - If you connect two calculators to each other with a circular cable you were also given, you can play it in multiplayer. 
- Another racing sim with better graphics ([Swervle.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/Swervle.g3a))
- Hoppy Road: amazing graphics, works smoothly ([HoppyRoad.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/HoppyRoad.g3a)) (only arrows)

# Games for GameBoy
While there are a few games made for this calculator, there are not that many of them. 
You can play most GameBoy games as well, but with a few extra steps.

## Emulator
First you need to install GameBoy Emulator. Just copy [prizoop.g3a](https://github.com/msbrickle/fx-CG50-games/blob/main/prizoop.g3a) on the calculator. 
Then just copy a GameBoy game you want to play (.gb extension) on the calculator. 
To launch a GameBoy game on the calculator, open Prizoop app on the calculator and select the game. Press f6 and then shift. You might need to exit and enter the game if it fails to load: press f1 and f6 again
## Tested games
The following games were tested:
- GTA 2 ([gta2.gbc](https://github.com/msbrickle/fx-CG50-games/blob/main/gta2.gbc)) (SHIFT is for accelerating/walking, arrows for direction, down arrow for going backwards slowly, SHIFT + f5 for entering/exiting the car, f6 to pause)
- Geometry Dash ([gb-dash_GB.gb](https://github.com/msbrickle/fx-CG50-games/blob/main/gb-dash_GB.gb)) (SHIFT for jumping)
- Mario ([Mario.gb](https://github.com/msbrickle/fx-CG50-games/blob/main/Mario.gb)) (arrows for movement, SHIFT for jumping)
- Tetris. No hard drop or hold ([tetris.gb](https://github.com/msbrickle/fx-CG50-games/blob/main/tetris.gb)) (arrow up for rotation, left and right for translation, down for speeding up)
- Space Invaders ([spaceinvaders.gb](https://github.com/msbrickle/fx-CG50-games/blob/main/spaceinvaders.gb)) (arrows for movement and SHIFT for shooting
- Kirby: standard gameboy in colour ([kirby.gb](https://github.com/msbrickle/fx-CG50-games/blob/main/Kirby.gb))
 
## Controls
- SHIFT: select or the specific action in the game
- f6: enter
- option, EXE and f5 do different things in different games
- Menu: leave the game
